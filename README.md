# 🛒 TechHub — Mobile Accessories E-Commerce Website

TechHub is a modern and responsive **mobile accessories e-commerce website** built using **HTML, CSS, and JavaScript**.

The website provides a clean shopping experience where users can explore products, browse categories, search for products, add items to the cart, and interact with different sections of the store.

---

## 🌐 Project Overview

**TechHub** is designed as a front-end e-commerce website for selling mobile accessories such as:

- 🔋 Power Banks
- 🔌 Chargers & Cables
- 📱 Device Holders
- 🎧 Audio Devices
- 🚗 Car & Travel Accessories
- 🧰 Other Mobile Utilities

The project focuses on creating a professional-looking shopping interface with smooth UI interactions and a user-friendly layout.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository


### 2. Open the project

## 💻 How It Works

### Product Search

Users can enter a product name in the search box to find relevant products.

### Add to Cart

When the user clicks **Add to Cart**, the selected product is added to the shopping cart and the cart count is updated.

### Buy Now

The **Buy Now** button provides a direct shopping flow for the selected product.

### Category Navigation

Users can select a category to explore products belonging to a specific accessory type.
